# Decision Architecture: publication history of BC-DS's work on the decision architecture discipline

Business Consultants for Digital Solutions, LLC (BC-DS), Rockville, Maryland.

This page records how BC-DS has published its work on the decision architecture discipline. It covers the framework papers by Monica M. Hernandez and Daniel A. Montero, and Monica M. Hernandez's articles and posts in English and Spanish, on LinkedIn and in PM World Journal. For each piece it gives the date and where anyone can check it. It records the publications of BC-DS and its two authors only. It makes no claim about who first used the words "decision architecture" or "arquitectura de decisiones", or about anyone else's use of them.

All times are given in UTC, with Rockville time beside them.

## How to check

1. **The time stamps.** Adobe Acrobat Reader shows each freetsa.org time stamp in its Signatures panel. The [README of Daniel-ams/BDA-Framework-v-1.00](https://github.com/Daniel-ams/BDA-Framework-v-1.00) gives the fingerprints of the files and of freetsa.org's certificates.
2. **The commits.** Each commit link above opens GitHub's record of it, with its date and GitHub's Verified mark.
3. **Zenodo.** Each DOI opens the Zenodo record, which shows the paper's date, its version and its files with their checksums.
4. **SSRN.** Each SSRN link opens the abstract page, which shows the date SSRN posted it and the Zenodo DOI.
5. **LinkedIn and PM World Journal.** Each link opens the piece. An article shows its date under the byline. A post's date is worked out from the number in its address, as explained in the section on Monica M. Hernandez's articles and posts.

## How this page is kept

Each new publication is added to this page as a row on the day it appears. No existing row is rewritten.

From this version on, the text of each version of this page, its file README.md, is time-stamped by freetsa.org under RFC 3161. A version cannot hold its own time stamp, so each version's stamp is added afterwards to the repository's folder `timestamps/`, with freetsa.org's request, reply and certificates. Each version is also saved to the Internet Archive's Wayback Machine.

To check a version without trusting BC-DS:

1. **The time stamp.** Take README.md as it stands at that version's commit, and its time-stamp reply from `timestamps/`. The command `openssl ts -verify -in reply.tsr -data README.md -CAfile cacert.pem -untrusted tsa.crt`, with freetsa.org's certificates from the same folder or from [freetsa.org](https://freetsa.org/), answers "Verification: OK" only if the text is unchanged since the stamp was made. The command `openssl ts -reply -in reply.tsr -text` shows the time in the stamp.
2. **The Wayback Machine.** [Its list of saved copies of this page](https://web.archive.org/web/*/https://bcds-llc.github.io/publication-history/) shows each copy with the date the Internet Archive saved it.

## How visits are counted

This page sets no cookies. To count visits, it loads a small script from Cloudflare Web Analytics. For each visit, it sends Cloudflare the page's address, where the visit came from, the browser and system versions, and how quickly the page loaded. Like any request, it reaches Cloudflare with the visitor's IP address. It sets no cookie and, as Cloudflare describes it, does not track individual visitors. GitHub, which serves this page, keeps its own records of the requests made to it.
